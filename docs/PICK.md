## 흐름 (`js/pick.js`, `css/pick.css`)

1. 화면: 제목, 한 줄 안내("고르기 귀찮을 땐 뽑기 한 번."), 밤하늘 무대 위의 뽑기 기계(먹방 월드컵과 같은 얼굴 달린 캡슐 기계, 220 × 330 을 화면에 맞게 줄임), 큰 버튼 **🎰 메뉴 뽑기**. 고를 것은 없다.
2. **뽑기**(약 1.8초): 손잡이가 세 번 돌며 공이 흔들리고 기계가 눈을 찡그리고, 작은 화면에는 음식 이모지가 지나가다 뽑힌 것의 이모지에서 멈춘다. 기계가 찌그러지며 입이 열리고 캡슐 하나가 튀어나와 기계 위로 날아가 통통 튀고, 껍데기가 날아가며 메뉴 사진(사진이 없으면 이모지)이 보인다. 기계는 뒤로 흐려지고, 버튼 아래에 결과 카드가 나온다. 뽑는 중에 버튼을 한 번 더 누르면 바로 결과다. 움직임 줄이기·고대비(forced colors)·Web Animations 미지원이면 움직임 없이 바로 결과다. 움직이는 것은 transform 과 opacity 뿐이고 기계는 장식(`aria-hidden`)이다. 버튼은 "뽑는 중…", 그다음 "다시 뽑기"가 된다.
3. **무엇을 뽑나**: 지금 먹을 수 있는 학식이 있으면 열 번에 네 번쯤은 학식, 나머지는 배달 메뉴(`BabdodukPick.draw`).
   - 학식: 오늘 날짜의 `data/kaist-menu/` 에서 본원 식당(건물 번호 E·W·N·S)의 끼니 중 아직 끝나지 않은 것(적힌 시간, 없으면 아침 9:30·점심 13:30·저녁 19:00) 하나. 카드: 🍱 학식 · 끼니, 식당, 메뉴(알레르기 번호와 칼로리 줄은 빼고), 시간·가격·건물, "학식 전체 보기"(`ggongbab.html#menu`).
   - 배달: 메뉴 사전(`data/foods/`)의 배달 가능한 메뉴를 배달앱처럼 치킨·피자·버거·족발보쌈·중식·분식·일식·아시안·양식·한식으로 나눈 것(앞의 종류부터 맞으면 거기, 한식은 마지막; `kindOf`) 중 인기도 4·5인 배달앱 단골 메뉴(`MIN_POPULARITY`, 2026-11-05 소유자 "배달음식이 너무나도 한국 정서와 조금 다른 것 같다": 인기도 3 이하 354개, 예: 루면·비앙비앙면이 다섯 번에 네 번 나왔다)이고 먹방 월드컵 사진(썸네일 `images/worldcup/thumb/`)이 있는 메뉴 하나, 인기도에 비례. 사진 출처는 `js/pick-photos.js` 에 있다: `scripts/sync_site_chrome.py` 가 `data/content/worldcup.json` `photos` 와 메뉴 사전에서 뽑힐 수 있는 메뉴 것만(같은 인기도 기준, `PICK_MIN_POPULARITY`) [작성자, 라이선스, 원본, 라이선스 링크 번호]로 써 넣는다(`data/content/` 는 배포되지 않으므로 페이지가 직접 읽지 않는다). 사진을 못 읽으면 사진 없는 메뉴까지 뽑고 캡슐에는 종류 이모지가 보인다. 카드: 🛵 배달 · 종류, 메뉴 이름, "가게와 가격은 배달앱에서 골라요.", 사진 출처(작성자 · 라이선스 링크).
4. **배달앱 연결은 나중에**: 2026-11-04 소유자 "이거는 나중에 구현. 조금 더 생각해보고 진행하자." 배민 앱 열기·메뉴 이름 복사는 넣지 않았다. 배민 데이터 수집·제휴도 소유자 검토 중.
5. 효과음: 손잡이 틱·캡슐 띵, 기본 꺼짐, 선택은 `localStorage` 의 `babdoduk-pick-sound`.
6. 언어를 바꾸면 버튼과 결과 카드가 그 언어로 다시 쓰인다(초점·스크롤은 그대로).

`js/eat-slot.js`(슬롯 릴)는 이 페이지에서 더 쓰지 않는다. 메뉴 사전 종류 이름(`data/content/labels.json` → `// @labels:` 블록)의 동기화 대상이라 파일은 남아 있고, 정리는 따로 한다.
