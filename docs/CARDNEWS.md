## 기본 양식 (`inputs/cardnews/`, lab 에 고정)

매주 같은 양식으로 그립니다. 바꾸고 싶으면 이 두 파일만 고치면 다음에 그리는 카드부터 반영됩니다(배포되지 않는 입력 폴더).

- `template.json`: 글귀(표지 머리말·합계·넘김 안내, 요일 카드 머리말·개수·"외 N개 더"·대상·서울 표시, 빈 요일 글귀, 아래 줄, 텔레그램 설명), 색(`colors`: 바탕, 종이, 잉크, 강조 분홍 등), 규칙(`rules`: 한 장에 몇 개 `perCard`, 촘촘한 배치 시작 `denseFrom`, 빈 요일 건너뛰기 `skipEmptyDays`, 제보로만 안 꽁밥 빼기 `skipTipOnly`, 바쁜 요일 다음 장으로 넘기기 `splitBusyDays`).
- `card.css`: 배치와 글자 크기. 색은 `template.json` 의 `colors` 가 `--canvas`, `--accent` 같은 변수로 들어옵니다.

## 카드

`scripts/render_cardnews.py` 가 그립니다. 시험은 `tests/test_cardnews.py`.

- 1080×1350(4:5) PNG: 1 표지, 그다음 꽁밥이 있는 요일마다 한 장(월~금). 한 장에 다 안 들어가는 요일은 다음 장으로 이어집니다(아래). 인스타그램 캐러셀은 모든 장을 첫 장 비율로 자르므로 모두 같은 크기입니다.
- 내용은 공개된 꽁밥 목록에서만 가져옵니다. 기본은 운영 사이트의 `https://babdoduk.vercel.app/data/ggongbab/latest.json` 이고(`--feed` 로 파일을 줄 수 있음), 목록이 만들어진 지 36시간이 넘었으면 그리지 않고 `FEED_STALE` 로 멈춥니다(`--allow-stale` 로만 넘김). 2026-11-02 카드는 작업 폴더에 있던 10-31 사본으로 그려졌습니다.
- 행사는 열리는 한국 날짜로 요일에 나눕니다. 목록에 회차(`sessions`)가 있으면 회차마다 그날 카드에 그 회차 시간으로 싣습니다(소유자 2026-11-03: 월~금 매일 열린 자연과학 토크 콘서트가 월요일 카드에만 있었음). 회차가 없으면 시작하는 날에만 싣습니다. 표지의 총 개수는 행사 수라서 여러 날 열리는 행사도 한 번만 셉니다. 주말 행사는 싣지 않습니다. 출처가 제보(`sources` 의 `tip`)뿐인 행사는 빼고, 메일 같은 다른 출처도 있으면 싣습니다.
- 표지: "이번 주 KAIST 꽁밥 캘린더", 월~금 날짜 범위, 요일별 개수(없는 날은 –), 총 개수.
- 요일 카드: 시작~끝 시간(끝이 같은 날일 때만), 행사 이름(두 줄까지), 음식 종류(`data/content/labels.json` 의 `freeFood`, 제공이 확인된 경우만), "서울" 표시(장소에 서울이 있을 때), 건물·호실, 대상(원문에 적힌 경우만).
- 3개 이상이면 촘촘한 배치, 한 장에 4개까지. 더 많으면 같은 요일 카드가 한 장 더 붙습니다(머리말에 "· 1/2", 소유자 2026-11-03: 빠지는 행사가 없게). `splitBusyDays` 를 끄면 예전처럼 "외 N개 더 · 사이트에서 확인하세요" 로 줄입니다. 4개를 채우면 대상 줄은 뺍니다.
- 꽁밥이 없는 요일은 카드가 없습니다(표지의 요일 칸에는 –). `skipEmptyDays` 를 끄면 "아직 알려진 꽁밥이 없어요" 카드가 들어갑니다.
- 모든 장 아래: "일정은 바뀔 수 있어요. 자세한 내용은 사이트에서 확인하세요.", `babdodukms.com` 링크 캡슐, 페이지 점과 쪽 번호. 원본 포스터는 싣지 않습니다.
- 글꼴은 운영 PC 에 설치된 Noto Sans CJK KR(시간은 DejaVu Sans). Chrome 으로 그립니다(`BABDODUK_BROWSER`, 기본 `chrome`).

## 만들기

```
python scripts/render_cardnews.py                    # 이번 주(토요일부터는 다음 주)
python scripts/render_cardnews.py --week 2026-11-02  # 그 월요일부터의 주
```

`data/cardnews/<월요일>/1.png`, `2.png`, … 를 쓰고(다시 그리면 그 주의 옛 카드를 먼저 지움), `data/cardnews/index.json` 맨 앞에 그 주를 넣습니다(같은 주를 다시 그리면 바꿔 넣음). 카드는 한 달만 보관합니다(소유자 2026-11-02): 가장 최근 주보다 31일 넘게 앞선 주는 목록에서 빠지고 그 주의 카드 폴더도 지웁니다. 각 주는 `counts`(월~금 개수), `total`(행사 수), `days`(요일 카드마다 그 요일, 0 = 월; 두 장인 요일은 두 번), `feedGeneratedAt`(그린 목록의 시각), `renderedAt`, `images` 를 가집니다.

`--send` 는 그린 카드를 소유자 텔레그램으로 보냅니다(운영 PC 의 봇, `--local ~/Babdoduk-ops/.local`): 2장 이상이면 앨범(`sendMediaGroup`, 텔레그램 한도인 10장씩, 맨 첫 장에 `template.json` 의 텔레그램 설명), 표지뿐이면 사진 한 장. 결과는 `PUSH_SENT` 같은 고정 코드이고 토큰은 남기지 않습니다. 이번 주(2026-11-02) 5장은 2026-11-02 소유자 확인 뒤 이렇게 보냈습니다.

## 보내기 전 점검 (소유자 2026-11-03)

그릴 때마다 모델 없이 코드로 점검하고, 결과를 표준 오류로 찍고 `--send` 면 카드 다음에 텔레그램 글로 보냅니다.

- 다시 읽기: 그린 카드에서 요일별 행사 이름을 다시 읽어, 목록에 그 주 평일에 있는 행사(회차가 있으면 회차마다)가 모두 그날 카드에 있는지 봅니다. 빠진 것은 "❗ 카드에 빠진 행사" 로 날짜와 이름을 적습니다.
- 여러 날인데 목록에 회차가 없어 첫날에만 실은 행사는 "ℹ️" 로 따로 적습니다.
- 검토 대기: 운영 PC 의 비공개 꽁밥 저장소에서 그 주에 열리는데 음식은 확인됐지만 검토 대기(`status = review`)라 사이트에도 카드에도 없는 행사를 읽기만 해서 이유와 함께 적습니다. 이 이름들은 텔레그램으로만 가고 공개 `index.json` 에는 들어가지 않습니다. 설정이 없거나 읽기에 실패하면 "읽지 못했어요" 라고 적고 카드는 그대로 만듭니다.
- 확인한 제보: 소유자가 ✅ 한 제보(`ggongbab_tips` 의 `accepted`) 중 그 주 평일인데 아직 꽁밥 목록에 없는 것을 "📮" 로 적습니다(소유자 2026-11-03: 확인된 제보는 꽁밥 일정에 들어가야 함). 제보는 수집함을 거쳐 다음 목록 갱신 때 들어가는데, 갱신은 30분마다로 잡혀 있어도 GitHub 이 실제로는 몇 시간 간격으로 돌립니다.
- 넘침: 그린 뒤 행사 이름이나 시간이 창 밖으로 넘친 카드가 있으면 "⚠️ n번 카드의 글이 창 밖으로 넘쳐요" 를 덧붙입니다(잘린 행사는 빠진 것과 같으므로).
- 출력 JSON 의 `check` 에는 개수와 넘친 카드 번호만 남습니다(`events`, `missing`, `firstDayOnly`, `held`, `tipsNotListed`, `clipped`). `--report <파일>` 이면 점검 글을 그 파일에도 씁니다(검토 대기 행사 이름이 들어갈 수 있으니 공개 폴더가 아닌 운영 PC 의 `.local` 에).

## 시안 페이지 (`cardnews.html`, `js/cardnews.js`, `css/cardnews.css`)

- `index.json` 의 가장 최근 주 카드를 순서대로 보여 줍니다(표지, 꽁밥이 있는 요일). 카드를 누르면 원래 크기로 열립니다.
- 위에 날짜 범위, 개수, 그린 꽁밥 목록의 시각을 적습니다. 페이지 글은 언어 전환을 따르고, 카드 속 글은 한국어입니다.

## 매주 자동 발송 (소유자 2026-11-08)

"항상 수집 내용은 오후 5시 30분 내용으로 해서 6시에 올려주세요." 2026-11-08 18:00 발송을 사람이 기억하는 데 맡겼다가 빠뜨린 뒤 타이머로 바꿨습니다. 운영 PC 의 systemd 사용자 타이머 두 개가 `~/.config/babdoduk/cardnews-weekly.sh` 를 부릅니다(저장소 밖, 운영 PC 설정).

| 타이머 | 시각 (Asia/Seoul) | 하는 일 |
|---|---|---|
| `babdoduk-cardnews-collect.timer` | 일요일 17:30 | 카드 전용 작업 폴더 `~/workspaces/Babdoduk-wt/cardnews-runner` 를 최신 `origin/lab` 으로 맞추고(그래서 lab 의 양식으로 그림), 그 시각의 운영 꽁밥 목록으로 그립니다: `render_cardnews.py --out ~/Babdoduk-ops/.local/cardnews-out --report …/check.txt` |
| `babdoduk-cardnews-send.timer` | 일요일 18:00 | 17:30 에 그린 카드와 점검 글을 다시 그리지 않고 보냅니다: `render_cardnews.py --send-drawn` |

- 둘 다 `Persistent=true`: PC 가 꺼져 있었으면 켜질 때 따라 돌고, 보내기는 그리기 뒤에 돕니다(`After=`).
- 어느 쪽이든 실패하면 소유자 텔레그램에 "⚠️ 이번 주 카드뉴스 만들기(17:30)/보내기(18:00)가 안 됐어요" 와 이유를 보냅니다. 기록은 `~/Babdoduk-ops/.local/cardnews-out/last-collect.log`, `last-send.log`.
- 카드 전용 폴더의 `.env` 는 운영 체크아웃 `.env` 로의 링크(검토 대기 점검용, 저장소에 없음)입니다.
- 확인: `systemctl --user list-timers 'babdoduk-cardnews*'`. 운영 PC 는 로그인 전에는 사용자 서비스가 돌지 않습니다(`Linger=no`).
