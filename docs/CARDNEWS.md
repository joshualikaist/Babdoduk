## 기본 양식 (`inputs/cardnews/`, lab 에 고정)

매주 같은 양식으로 그립니다. 바꾸고 싶으면 이 두 파일만 고치면 다음에 그리는 카드부터 반영됩니다(배포되지 않는 입력 폴더).

- `template.json`: 글귀(표지 머리말·합계·넘김 안내, 요일 카드 머리말·개수·"외 N개 더"·대상·서울 표시, 빈 요일 글귀, 아래 줄, 텔레그램 설명), 색(`colors`: 바탕, 종이, 잉크, 강조 분홍 등), 규칙(`rules`: 한 장에 몇 개 `perCard`, 촘촘한 배치 시작 `denseFrom`, 빈 요일 건너뛰기 `skipEmptyDays`, 제보로만 안 꽁밥 빼기 `skipTipOnly`).
- `card.css`: 배치와 글자 크기. 색은 `template.json` 의 `colors` 가 `--canvas`, `--accent` 같은 변수로 들어옵니다.

## 카드

`scripts/render_cardnews.py` 가 그립니다. 시험은 `tests/test_cardnews.py`.

- 1080×1350(4:5) PNG: 1 표지, 그다음 꽁밥이 있는 요일마다 한 장(월~금, 많아야 6장). 인스타그램 캐러셀은 모든 장을 첫 장 비율로 자르므로 모두 같은 크기입니다.
- 내용은 공개된 꽁밥 목록 `data/ggongbab/latest.json` 에서만 가져옵니다. 행사는 시작 시각의 한국 날짜로 요일에 나눕니다. 주말 행사는 싣지 않습니다. 출처가 제보(`sources` 의 `tip`)뿐인 행사는 빼고, 메일 같은 다른 출처도 있으면 싣습니다.
- 표지: "이번 주 꽁밥", 월~금 날짜 범위, 요일별 개수(없는 날은 –), 총 개수.
- 요일 카드: 시작~끝 시간(끝이 같은 날일 때만), 행사 이름(두 줄까지), 음식 종류(`data/content/labels.json` 의 `freeFood`, 제공이 확인된 경우만), "서울" 표시(장소에 서울이 있을 때), 건물·호실, 대상(원문에 적힌 경우만).
- 3개 이상이면 촘촘한 배치, 한 장에 4개까지. 더 많으면 "외 N개 더 · 사이트에서 확인하세요". 4개를 채우면 대상 줄은 뺍니다.
- 꽁밥이 없는 요일은 카드가 없습니다(표지의 요일 칸에는 –). `skipEmptyDays` 를 끄면 "아직 알려진 꽁밥이 없어요" 카드가 들어갑니다.
- 모든 장 아래: "일정은 바뀔 수 있어요. 자세한 내용은 사이트에서 확인하세요."와 쪽 번호. 원본 포스터는 싣지 않습니다.
- 글꼴은 운영 PC 에 설치된 Noto Sans CJK KR(시간은 DejaVu Sans). Chrome 으로 그립니다(`BABDODUK_BROWSER`, 기본 `chrome`).

## 만들기

```
python scripts/render_cardnews.py                    # 이번 주(토요일부터는 다음 주)
python scripts/render_cardnews.py --week 2026-11-02  # 그 월요일부터의 주
```

`data/cardnews/<월요일>/1.png`, `2.png`, … 를 쓰고(다시 그리면 그 주의 옛 카드를 먼저 지움), `data/cardnews/index.json` 맨 앞에 그 주를 넣습니다(같은 주를 다시 그리면 바꿔 넣음). 카드는 한 달만 보관합니다(소유자 2026-11-02): 가장 최근 주보다 31일 넘게 앞선 주는 목록에서 빠지고 그 주의 카드 폴더도 지웁니다. 각 주는 `counts`(월~금 개수), `total`, `days`(카드가 있는 요일, 0 = 월), `feedGeneratedAt`(그린 목록의 시각), `renderedAt`, `images` 를 가집니다.

`--send` 는 그린 카드를 소유자 텔레그램으로 보냅니다(운영 PC 의 봇, `--local ~/Babdoduk-ops/.local`): 2장 이상이면 앨범 하나(`sendMediaGroup`, 첫 장에 `template.json` 의 텔레그램 설명), 표지뿐이면 사진 한 장. 결과는 `PUSH_SENT` 같은 고정 코드이고 토큰은 남기지 않습니다. 이번 주(2026-11-02) 5장은 2026-11-02 소유자 확인 뒤 이렇게 보냈습니다.

## 시안 페이지 (`cardnews.html`, `js/cardnews.js`, `css/cardnews.css`)

- `index.json` 의 가장 최근 주 카드를 순서대로 보여 줍니다(표지, 꽁밥이 있는 요일). 카드를 누르면 원래 크기로 열립니다.
- 위에 날짜 범위, 개수, 그린 꽁밥 목록의 시각을 적습니다. 페이지 글은 언어 전환을 따르고, 카드 속 글은 한국어입니다.
- 진입: lab 주소에서 모든 페이지의 더보기 "카드뉴스"(`js/site.js` LAB_LINKS, 실험 페이지는 `scripts/sync_site_chrome.py` LAB_LINKS).
